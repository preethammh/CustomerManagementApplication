# AI Usage

## AI tools used
  - Google gemini
  - GH copilot

## Backend
  Most of the code(apart from test cases) is handwriteen using autocompletion.

## Frontend
  Since I had not worked on react from past 2 years, used VS code planning mode to create the plan
  After the planning most of the code is generated by the agent, but reviewed all the code generated by the agent before accepting.

## Time taken
  The backend took roughly 2.5 hours in total, this is a rough estimation as most of the work was done in a staggered way
  The frontend took 2 hours in total, without the AI it would have take more time in generating the CSS and HTML stuff, approximately around 5hours.
  So in total I had spent around 4 to 5 5hrs to complete the entire project.
